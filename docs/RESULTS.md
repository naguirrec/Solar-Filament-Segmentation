## How to add a result

1. Copy a row in the table.
2. Fill in the date, what ran (notebook and pull request), the settings, the holdout metric and which metric version it is, the public leaderboard score if you submitted, and a note.
3. Put a small CSV in `results/`, named with the date, for example `results/2026-11-01_postprocess_sweep_unet12ep.csv`.
4. Do not commit images, weights, or submission files.
